Audiobook Splitter

Split long audio files at the middle of each silence.

Files

When set, a local speech-to-text model listens around each silence and the app splits only where the narration matches the start of an EPUB chapter. Files are named after the chapters.
Created if it doesn't exist. Existing splits are never overwritten.

Detection

Shorter values find more split points.
Less negative values treat more sound as silence.
EPUB only. How closely the narration must match a chapter opening (0 to 1).
